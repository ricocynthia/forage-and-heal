# Your photos

Put your own pictures here, one folder per species. The folder name is the species name in
lower case with dashes:

```
src/photos/elderberry/01-in-flower-early-summer.jpg
src/photos/elderberry/02-ripe-berries-early-autumn.jpg
src/photos/chicken-of-the-woods/on-an-oak-stump.jpg
```

That is all. The next time the app is built, a "From the field" section appears on that
species' page. Species with no folder (or an empty one) simply don't show the section.

- **Order:** photos are shown in file name order, so start names with 01, 02, 03 to arrange them.
- **Captions:** the file name becomes the caption. `02-ripe-berries-early-autumn.jpg` reads
  "Ripe berries early autumn". Camera names like `IMG_1234.jpg` get no caption.
- **Formats:** jpg, png, webp or avif. Around 1600 px on the long side is plenty.

Folder names: burdock, catnip, dandelion, echinacea, elderberry, goldenrod, motherwort, mullein,
stinging-nettle, yellow-dock, chaga, morel, maitake, lions-mane, oyster-mushroom,
cauliflower-mushroom, chicken-of-the-woods, chanterelle, giant-puffball, turkey-tail.
